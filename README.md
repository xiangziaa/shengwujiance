# Grain Safety Intelligence · 粮安智检 2.0

粮食安全检测演示平台，包含样本管理、快速筛查、ELISA / qPCR 分析、AI 综合判读、报告中心和数字人小安。当前应用使用本地演示数据和规则问答，无需启动后端服务。

- [AI 大屏](https://60.205.6.104/ai-screen)
- [小安设置](https://60.205.6.104/voice-settings)

## 本地运行

建议使用 Node.js 22.12+ 或 Node.js 24 LTS，以及 npm。

在仓库根目录执行：

```powershell
npm run setup
npm run dev
```

打开 [http://localhost:5173](http://localhost:5173)。开发服务监听 `0.0.0.0`；如默认端口已占用，以终端输出为准。

### Windows 一键启动网页和 ASR

首次安装 Node.js 和 Python 后，在项目根目录执行（安装时需要联网）：

```powershell
npm run setup
powershell -ExecutionPolicy Bypass -File local-asr/setup.ps1
```

之后双击根目录的 `start-dev.bat`，即可同时运行 `npm run dev` 和本地 ASR。启动器会检查依赖、模型和端口；检测到已运行的开发网页或 ASR 时会复用。网页固定使用 http://localhost:5173，ASR 使用 http://127.0.0.1:8767，不启动 TTS。

前端和 ASR 各自打开一个服务窗口，日志和启动错误直接显示在窗口中。使用时保留这两个窗口，停止时关闭对应窗口即可；关闭 BAT 提示窗口不会停止服务。

### 工作台日期

- “数据更新于”在每次进入工作台时读取浏览器所在设备的系统时间，停留期间保持不变。
- 趋势图的“近 7 天”和“近 30 天”均以进入页面当天为结束日期，自动处理跨月、跨年日期。
- 内置样本的检测日期分布在最近几天；编号采用 `S + YYYYMMDD + 四位序号`，日期与检测时间一致，名称和批次中的日期也同步生成。
- 跨天重新进入工作台时，会更新内置演示样本日期，并同步样本、报告和复核记录的关联；用户新增的样本不参与该日期迁移。
- 高风险样本按检测时间从新到旧展示。趋势数量仍是演示数值，不代表实时采集的检测结果。

### 其他日期与时间

- 工作台问候语按进入页面时的时段显示，页脚年份随系统年份更新。
- 知识库在每次进入时生成最近几天的演示更新日期，停留期间不跳动；标准名称中的正式版本年份保持不变。
- 报告编号日期在进入报告中心及预览、切换、签字、导出或打印时更新；导出、打印使用本次操作的时间。报告内部 ID 保持稳定，避免影响关联。
- 新建样本表单中的名称示例日期随打开表单更新。样本采样、检测时间保持原有规则。
- 以上均按进入或操作更新，不使用每秒定时刷新。

### 关键词音频播放

小安已改为直接播放用户选择的音频，不再调用 Qwen、微软在线语音或本地 TTS 服务。

- 在“小安设置”中为每条关键词选择 MP3、WAV 等音频（单个不超过 50 MB），试听后保存全部设置。
- 支持启用开关、播放前警报及停止播放。未配置音频时不播放声音。
- 文件副本保存在当前浏览器 IndexedDB 中，刷新后可播放，不需要后台语音服务。清除站点数据、换浏览器或电脑后需重新选择文件；不自动上传 GitHub。
- 关键词识别继续使用现有本地 ASR 服务，手动播放不需要 ASR。
- 修改后显示保存提示，保存前只影响试听，正式触发仍使用已保存设置。

### AI 大屏

右侧提供 5 个快捷提问：查看高风险预警、今日待复核任务、介绍检测流程、查看样本总数、如何生成检测报告。

左侧“手动播报”自动显示已保存、已启用且内容有效的关键词映射：

- 按钮宽度一致，标题取关键词前 **8 个字符**，超长部分显示省略号，悬停可查看完整关键词。
- 点击按钮播报对应内容，再次点击正在播报的按钮可停止；点击其他按钮会切换播报内容。
- 手动播报直接播放映射绑定的音频并遵守警报设置。即使当前关闭声音，主动点击播报按钮也会开启声音。
- 映射保存、停用或删除后，按钮列表同步更新；列表较长时可滚动查看。

音频播放无需 TTS、GPU 或网络服务。历史 local-tts 目录只作旧方案资料保留，不参与当前网页播放流程。

## 构建与验证

以下命令均在仓库根目录执行：

```powershell
npm run typecheck
npm test
npm run build
npm run preview
```

`build` 包含 TypeScript 检查并生成 `frontend/dist/`。语音测试覆盖映射、识别状态、播报取消、警报顺序、语速及设置持久化；日期测试覆盖最近 7 / 30 天、跨月跨年、闰年、样本编号和跨天关联迁移。

## 部署

当前生产环境通过 Nginx 提供 `frontend/dist/` 静态文件，HTTPS 入口为 `https://60.205.6.104`；HTTP 的 `8084` 端口重定向到 HTTPS。

| 项目 | 路径 |
| --- | --- |
| 版本目录 | `/var/www/shengwujiance-releases/<UTC时间戳>/` |
| HTTPS 配置 | `/etc/nginx/conf.d/shengwujiance-https.conf` |
| HTTP 重定向配置 | `/etc/nginx/conf.d/lvyu-nginx-8084.conf` |
| 当前部署记录 | `deploy/latest-deployment.json` |
| 健康检查 | `https://60.205.6.104/healthz`，正常返回 `ok` |

发布步骤：

1. 在本地完成测试并执行 `npm run build`。
2. 将 `frontend/dist/` 内的文件打包上传，解压至新的版本目录，确保 `index.html` 直接位于该目录下。
3. 备份当前 HTTPS 配置，将其 `root` 切换到新版本目录。
4. 执行 `nginx -t`，通过后执行 `systemctl reload nginx`。
5. 等待重载生效，验证页面路由、JS / CSS 资源、文件哈希及 `/healthz`，再更新部署记录。
6. 如验证失败，恢复备份配置并重新检查、重载 Nginx。保留旧版本目录以便回滚。

React Router 的页面路由需要 Nginx 配置 `try_files $uri $uri/ /index.html`。入口 HTML 应禁用缓存；带哈希的静态资源可长期缓存。SSH 凭据由运维单独管理，不写入仓库。

## 目录结构

```text
frontend/                  Web 应用（grain-safety-intelligence-web）
  src/                     页面、组件、状态、演示数据和工具
  public/                  网站运行时使用的静态资源
  scripts/                 素材处理脚本
  tests/                   语音与日期回归测试
  package-lock.json        前端依赖锁定文件
  dist/                    构建输出（忽略提交）
assets/source/             当前使用的原始素材与生成记录
deploy/                   部署资料
  nginx/site.conf.example  Nginx 配置模板
  latest-deployment.json   本机部署记录（忽略提交）
docs/                      项目维护说明
package.json               根目录统一命令入口
README.md                  项目说明
```

技术栈：React 19、TypeScript、Vite 8、Ant Design 6、ECharts 6、Zustand、React Router 和 Day.js。

样本、报告等业务状态保存在内存中，刷新会重新初始化；小安设置单独持久化到浏览器存储。AI 问答使用本地规则，未接入远程大模型。

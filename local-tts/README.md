# 小安本地 TTS

主服务使用 Python 标准库。Qwen 模型及独立 GPU 环境安装见 [NEW-ASSISTANT-MODELS.md](NEW-ASSISTANT-MODELS.md)。
模型已下载的电脑不需要再次下载，之后合成无需互联网。

从项目目录运行 `powershell -ExecutionPolicy Bypass -File .\local-tts\start-local-tts.ps1`，保持服务运行。
在小安设置中查看连接状态并点击“重新检测”。网页使用电脑必须运行此服务；127.0.0.1 指使用浏览器的电脑。
如浏览器提示本地网络访问权限，请允许。服务监听 127.0.0.1:8765，不对局域网开放。

GET /health 返回实际加载的本地声线；POST /tts 接收 text、voice、rate，返回 WAV。
模型在启动时加载一次。默认使用 Qwen Vivian；已有语音文件直接读取，不需要 Qwen 显卡服务在线。尚未生成的内容需要对应模型可用，不回退系统或在线声线。
不再需要 Voicemeeter 或录音权限。旧配置中的系统声线自动迁移到服务默认声线。
语音识别仍使用浏览器能力，离线播报可通过手动按钮或文字提问触发。


## Qwen 女声

当前只接入 Qwen3-TTS 1.7B CustomVoice 的全部四条女声：Vivian（默认，中文）、Serena（中文）、Ono_Anna（日语原生）、Sohee（韩语原生）。所有播报仍指定 Chinese 语言；日、韩原生声线的中文口音和自然程度需试听确认。

其他模型从声线列表和主服务加载逻辑移除。旧映射中的其他模型 ID 自动迁移为默认 Vivian，保留文本、开关、语速和警报设置。历史评估脚本与模型文件不参与当前服务。

生成新的 Qwen 文件需同时运行 `powershell -ExecutionPolicy Bypass -File .\local-tts\start-qwen.ps1`。已有文件仍只需主服务。

## 预生成与项目本地文件

设置页“保存全部设置”逐条调用 `POST /prepare`，显示加载动画、完成数量和当前关键词；包括暂时停用的映射。全部 WAV 写入成功后才提交浏览器设置。失败时保留旧设置及已生成文件，重试可复用已完成文件。

音频保存在 `local-tts/audio/<voice>/<hash>.wav`，不是浏览器缓存。文本（含术语展开）、声线、语速和生成版本共同确定文件名；改关键词或警报开关不重复合成，修改播报内容、声线或语速会生成新文件。写入先验证 WAV，再原子替换，损坏文件会重新生成。旧文件保留以便复用；当前音频目录中的 Qwen WAV 文件均随仓库提交，拉取项目即可获得。

`POST /tts` 先读已有文件，命中时不调用模型，也不受其他语音生成任务阻塞；未命中时生成并保存。播放已有文件仍需运行 8765 主服务，但不需互联网或 8766 Qwen 服务。设置本身仍保存在当前浏览器。

运行 `python local-tts/prepare_defaults.py` 预生成前端实际默认的 5 条播报（欢迎语及 4 条业务预设），覆盖 Vivian、Serena、Ono_Anna、Sohee 与稍慢、标准、稍快的全部 60 种组合。脚本逐条保存进度，可重复运行并复用已生成文件。

仓库随附这 60 份 WAV 和 `local-tts/audio/defaults-all.json` 清单，清单记录文本、关键词、声线、节奏、文件路径、时长和 SHA-256。所有 Qwen 本地 WAV 和音频清单均纳入 Git，files.json 记录本次发布的完整文件列表。模型和 Python 虚拟环境仍不上传。

运行 `python local-tts/verify_defaults.py` 验证全部组合、文件完整性和哈希；主服务启动后可加 `--http` 验证每条语音返回的 WAV 与磁盘文件一致。新机器仅播放这些预设时，运行标准库主服务即可，无需安装 GPU 模型；更改文本后需安装并启动 Qwen 生成新语音。

## Qwen 自然语速

设置页提供“稍慢／标准／稍快”。Qwen 将节奏要求直接传入模型，不使用 librosa 时间拉伸；不承诺精确倍速。旧数值小于 1 映射稍慢，大于 1 映射稍快，等于 1 保持标准。

非标准 Qwen 音频使用新版文件标识，旧的倍速拉伸文件不再命中；标准语速指令未变，默认预生成文件继续复用。修改节奏后保存全部设置会生成新文件。

## 在另一台电脑播放

1. 安装 Python 3，拉取最新项目（包含 local-tts/audio 的 WAV）。
2. 在项目根目录运行 `python local-tts/server.py` 并保持窗口运行；只播放已有文件不需要 pip 安装依赖、Qwen 权重或显卡。
3. 按项目 README 启动网页，在小安设置中确认本地语音已连接，即可手动播报默认关键词。

默认 5 条播报覆盖全部女声和节奏。已有文件按文本、声线和节奏匹配；改成未生成的新内容仍需 Qwen。浏览器保存的自定义关键词映射不随 Git 同步，在另一台电脑配置相同文本、声线和节奏后可复用对应音频。
